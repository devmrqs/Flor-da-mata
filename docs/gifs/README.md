# GIFs de animação

Pasta onde ficam os GIFs referenciados no `README.md` principal. Grave cada um (ex: com [ScreenToGif](https://www.screentogif.com/) no Windows, ou [Peek](https://github.com/phw/peek) no Linux) e salve aqui com o nome exato esperado — o README já está com os links prontos, só falta os arquivos existirem.

Recomendações de gravação:

- Resolução de captura ~1280px de largura, depois comprimir (ex: [ezgif.com](https://ezgif.com/optimize) ou `gifsicle -O3`) para manter o arquivo leve — GitHub carrega tudo de uma vez, sem lazy load.
- Duração curta (3–6s), em loop, sem cursor do mouse visível se possível.
- Fundo/viewport consistente entre os GIFs (mesma largura de janela) para não ficar desalinhado no README.

| Arquivo esperado | O que gravar |
|---|---|
| `hero-entrance.gif` | Carregar `/` do zero: timeline do Hero (título "A", NATUREZA, slogan, botões, seta pulando) |
| `hero-pin-products.gif` | Rolar a partir do topo da Home: pin do Hero encolhendo/fade enquanto o card do Products sobe por cima |
| `navbar-entrance.gif` | Reload da página mostrando os links da Navbar entrando com stagger |
| `button-hover.gif` | Hover num botão `primary`: texto encolhendo e círculo da seta crescendo |
| `category-carousel.gif` | Home ou Products: auto-scroll do carrossel de categorias + expandir um card |
| `product-modal.gif` | Abrir um produto: galeria de thumbnails, troca de imagem, seleção de gramagem |
| `scroll-smoother.gif` | Scroll geral pela página mostrando a suavização do ScrollSmoother |
